# Images Guide

This directory contains all images for your personal website.

## Directory Structure

```
images/
├── profile/          # Profile photos
├── projects/         # Project screenshots and images
└── README.md         # This file
```

## Recommended Images to Add

### Profile Photo
**Location:** `images/profile/`
**Recommended filename:** `profile.jpg` or `profile.png`
**Dimensions:** 400x400px minimum (square)
**Usage:** Hero section on home page

## Image Optimization Tips

1. **Format:** Use JPG for photos, PNG for graphics with transparency
2. **Compression:** Optimize images to keep file sizes under 500KB
3. **Tools:** Use tools like TinyPNG, ImageOptim, or Squoosh
4. **Alt Text:** The website will automatically use descriptive alt text

## Placeholders

The website is designed to work with placeholders if images aren't available yet. Simply add your images when ready using the filenames above!

## Optional: Speaking/Event Photos

If you want to add photos from speaking engagements:
- Create a `speaking/` subdirectory
- Add photos from TEDx talks, conferences, etc.
- Recommended dimensions: 1200x675px (16:9)
